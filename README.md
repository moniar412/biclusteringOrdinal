# biclusteringOrdinal
Title: A novel model-based biclustering for ordinal data via an URV approach

Author: Monia Ranalli and Francesca Martella

Questions, comments and remarks about the code should be addressed to: Monia Ranalli, email: monia.ranalli at uniroma1.it

In order to reproduce a simulation study one can use files: sim1.R, sim2.R, sim3.R, sim4.R, sim5.R.

The main functions are randmixBicl.R to generate data, stPoint.R to generate a rational starting point, EMbicl.R to get the parameter estimates, t3postProb1.R to get the posterior probabilities.

The files shall be run in R.
